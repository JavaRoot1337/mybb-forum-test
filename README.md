# MyBB

Исходный код форума MyBB с темой JavaRoot Resources.

## Запуск

Требуется PHP 8.2 или новее. Для локального запуска используйте [`start.bat`](start.bat). Сервер работает на `http://127.0.0.1:8080/` с каталогом `public/` в качестве web-root.

## Структура

- `public/` — публичные страницы, Admin CP, MyBB core, тема и ресурсы;
- `config/` — Composer и конфигурации проверок;
- `tests/` — тесты;
- `docs/` — архитектура и deployment-шаблоны;
- `tools/` — локальные runtime-инструменты.

Публичные URL MyBB сохраняются. Скрытые файлы Git и CI остаются техническими исключениями в корне.
