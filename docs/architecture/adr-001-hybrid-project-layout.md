# ADR-001: гибридная структура web-root и внутренних каталогов

## Статус

Принято

## Контекст

Проект использует legacy-структуру MyBB, в которой корень репозитория одновременно является web-root. Публичные PHP-файлы, `inc`, `admin`, `install`, `images`, `jscripts`, `cache` и `uploads` участвуют в прямых URL, относительных `require` и внутренних проверках MyBB.

Одновременно в корне находились служебные deployment-шаблоны и локальные runtime-инструменты, которые можно сгруппировать без изменения поведения форума.

## Решение

Сохранять контрактные MyBB-каталоги и публичные entrypoint-файлы на прежних местах. Служебные файлы раскладывать по назначению:

- deployment-шаблоны хранить в `docs/deployment`;
- локальные PHP/Composer и архивы хранить в `tools/runtime`;
- запускающие скрипты хранить в `tools/scripts`;
- архитектурные решения хранить в `docs/architecture`.

Корневые конфигурации Composer, PHPUnit, PHPCS, PHPStan, Psalm и CI остаются в корне, потому что это стандартные точки обнаружения инструментов.

## Последствия

Публичные URL, пути MyBB, plugin/theme-контракты, namespaces, база данных и HTTP API не меняются. Локальный сервер запускается из `tools/scripts/start.bat`, который вычисляет корень проекта относительно собственного расположения.

Отдельный `public`-root не вводится: для него потребовалась бы массовая перестройка bootstrap-файлов и web-server-конфигурации.
